# BT-Chat - צ'אט דרך בלוטוס (Android ⇄ Windows)

אפליקציית Android (Kotlin) ותוכנת Windows (WPF/.NET) שמדברות ביניהן ישירות דרך
**Bluetooth Classic (SPP)**: הודעות, קבצים ותמונות, בכל שילוב (אנדרואיד⇄אנדרואיד,
ווינדוס⇄ווינדוס, אנדרואיד⇄ווינדוס). הפרוטוקול המשותף מתועד ב-[`PROTOCOL.md`](PROTOCOL.md).

## חדש בגרסה 2.1
- **העברה מהירה ב-Wi-Fi**: קבצים מ-1MB ומעלה עוברים אוטומטית ברשת המקומית כששני המכשירים
  מחוברים לאותה רשת או לנקודה חמה. זה עובד גם בלי אינטרנט, ומהיר פי 20 עד 100.
  כשאין רשת משותפת, הקבצים עוברים ב-Bluetooth כרגיל. אפשר לכבות את זה בהגדרות.
- **ניקוי קבצים זמניים** (אנדרואיד, בהגדרות): מוחק תמונות שצולמו מתוך הצ'אט. עותקים מוקטנים
  נמחקים עכשיו מיד אחרי השליחה, בשני הצדדים.
- **תפריט שלוש הנקודות** באנדרואיד: הכיתוב בו קריא עכשיו.
- **מהדורת טיוטה**: כל בנייה ב-Actions יוצרת גם טיוטה בדף Releases, עם ה-APK וה-EXE.

## מה יש בגרסה 2.0
- **פתוח לחיבורים אוטומטית**: אין צורך ללחוץ "האזן". כל חיבור נכנס מבקש אישור, ואפשר לסמן
  "אשר תמיד את המכשיר הזה".
- **צימוד מתוך האפליקציה**: חיפוש מכשירים בסביבה וצימוד, בלי להיכנס להגדרות המערכת.
- **היסטוריית שיחה נפרדת לכל מכשיר**, עם שעה ליד כל הודעה וסימון אם נשלחה.
- **שם לכל מכשיר**: כינוי שמוצג רק אצלך.
- **קבצים**: נשמרים כברירת מחדל ב-`הורדות/BT Chat`, ואפשר לבחור תיקייה אחרת בהגדרות.
  לחיצה על קובץ בצ'אט פותחת אותו. ב-Windows יש גם "הצג בתיקייה" ו"העתק נתיב".
  בזמן העברה מוצג פס התקדמות, ותמונות מוצגות בצ'אט כתמונה ממוזערת.
- **צילום מהצ'אט** (באנדרואיד) ישירות עם אפליקציית המצלמה.
- **שליחת תמונות באיכות מוקטנת** (עד 1600 פיקסלים, JPEG 75%). זה מהיר בערך פי 10.
  אפשר לבחור בכל שליחה או לקבוע בהגדרות.
- **התראות קופצות** כשהאפליקציה ברקע, עם אפשרות כיבוי בהגדרות.
- **החיבור לא נופל** כשמסובבים את הטלפון או מסתירים את האפליקציה. באנדרואיד יש שירות
  ברקע עם התראה קבועה. ב-Windows התוכנה ממשיכה לפעול ליד השעון כשסוגרים את החלון
  (אפשר לכבות את זה בהגדרות).
- כפתור **התנתק**, **שיתוף ל-BT Chat** מהגלריה באנדרואיד, **גרירת קבצים** לחלון ב-Windows.
- אייקון חדש, עיצוב חדש שמתאים גם למסכים קטנים, ומצב כהה באנדרואיד.
- דרישת מינימום: **Android 10 ומעלה**.

## העלאה ובנייה
1. בריפו ב-GitHub: **Add file → Upload files**, וגררו לתיבת ההעלאה את **כל התוכן** של
   התיקייה (`android`, `windows`, `.github`, `README.md`, `PROTOCOL.md`).
   קבצים עם אותו שם יוחלפו. הגרסה הזו לא מוחקת אף קובץ קיים, רק מחליפה ומוסיפה.
2. **Commit changes**. ה-workflow רץ אוטומטית.
3. ב-**Actions**, ב-run האחרון, תחת **Artifacts**:
   - `BtChat-android-apk` מכיל את `app-release.apk`
   - `BtChat-windows-exe` מכיל את `BtChat.exe`

ה-APK חתום תמיד באותו מפתח (`keystore/release.jks`), ולכן הוא מותקן מעל הגרסה הקודמת בלי להסיר אותה.

## שימוש
1. פתחו את BT Chat בשני המכשירים. שניהם מוכנים לקבל חיבור.
2. בצד אחד: **התחבר למכשיר** (אנדרואיד) או לחיצה כפולה על מכשיר ברשימה / **התחבר** (Windows).
   מכשיר שעוד לא מזווג: **חפש מכשירים חדשים** / **צמד מכשיר חדש**.
3. בצד השני מופיעה בקשת חיבור: **אשר** (ואפשר לסמן "אשר תמיד").

## הערה על אבטחה
מפתח החתימה מוטמע בריפו כדי שהכל יעבוד בלי הגדרה ידנית. זה בסדר לריפו **פרטי** לשימוש
אישי. אם הריפו יהפוך לציבורי, כדאי להעביר את הסיסמה והמפתח ל-GitHub Secrets.

## הערות טכניות
- **Windows**: 32feet.NET (`InTheHand.Net.Bluetooth`). ההגדרות וההיסטוריה נשמרות ב-`%APPDATA%\BtChat`.
- **Android**: ההגדרות וההיסטוריה נשמרות בתוך האפליקציה. הרשאות `BLUETOOTH_CONNECT`/`BLUETOOTH_SCAN`
  (Android 12+), ובאנדרואיד 10-11 הרשאת מיקום, שנדרשת רק לחיפוש מכשירים חדשים.
